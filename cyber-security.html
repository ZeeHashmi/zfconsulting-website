Authorised and carefully scoped

Assessments are conducted only with appropriate authorisation from the system owner or their authorised representative. Scope, timing and permitted methods are agreed before work begins. Passive security assessments review information observable without attempting to exploit a weakness or alter a system. Active testing, including API security testing and penetration testing, sends test inputs or probes to a target and is performed only with explicit authorisation and an agreed scope. No assessment can guarantee that a website or application is completely secure.
