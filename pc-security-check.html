Is your Windows PC properly protected?

Run a simple, read-only PC security health check. Review selected Windows security settings and create a report on your own computer.

Download Windows Health Check How it works

What does the check review?

Microsoft Defender

Checks whether Defender is available and reports selected protection status indicators.

Windows Firewall

Checks whether the Domain, Private and Public firewall profiles are enabled.

Windows information

Reports Windows edition, version and the most recently installed hotfix visible to Windows.

Local HTML report

Creates a report on your computer that you can review before choosing to share it.

How it works

  1. Download the PowerShell assessment script.
  2. Review the script before running it. It is designed to read selected Windows security settings only.
  3. Run it on your Windows PC using your normal user account. Administrator rights are not required for the checks we perform.
  4. Open the generated HTML report and review the findings.
Download the assessment script

Important limitations

This is a security health check, not a malware scanner or forensic investigation. A healthy result does not prove that a computer has never been compromised. This first version does not inspect personal files, collect passwords, read browser history, upload data or send information to ZF Consulting Services.

The report is generated and saved locally on your computer. Email report delivery and aggregate usage analytics will be added only after a secure backend and privacy controls are configured.
