Featured project 02 · Open source

AI Security Test Suite

AI is powerful, but it can also be vulnerable. This Playwright and TypeScript project uses automated scenarios and pattern-based response checks to help teams assess how AI systems handle common security risks.

Three threat categories

Prompt injection, jailbreak attempts, and data leakage or personal information exposure.

19 automated test cases

Scenario-based checks with pattern-based response validation to help review test outcomes.

Built for practical testing

Includes mock mode for safe testing and is designed to fit into continuous integration pipelines.

Designed for QA engineers moving into AI, security testers exploring LLM risks, and teams integrating AI into production. These checks support security reviews; they do not guarantee that an AI system is secure.
